# Screenshots

This folder is reserved for **sanitized product screenshots**.

Planned examples:

1. Home chat / room interface
2. Memory / Context Health view
3. Architecture or workflow preview
4. Selected debug / acceptance evidence where no private data is visible

## Publication Rules

Before adding any screenshot:

- remove names or personal conversation content that is not intended for public release
- remove API keys, tokens and account identifiers
- remove local absolute paths
- remove private memory contents
- remove internal email / phone / address data
- remove production database identifiers unless intentionally public
- verify browser tabs, notifications and sidebars do not expose unrelated information

The goal is to demonstrate product and system behaviour without publishing private production state.
